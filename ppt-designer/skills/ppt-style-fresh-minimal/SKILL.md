# 清新极简风 · 设计系统（Fresh Minimal）

参考气质：Notion、无印良品、教育类产品官网。关键词：轻盈、友好、透气、低饱和、圆角。

## 何时使用
教学课件、知识分享、读书笔记、个人汇报、SaaS/轻产品介绍、社群分享。主题词里出现"入门、指南、笔记、分享、成长、轻量"时优先匹配。

## 色彩系统
| 角色 | 色值 | 用途 |
|---|---|---|
| 画布底色 | `#FAFAF8` 暖白 | 每页背景 |
| 主文字 | `#2D2A26` | 标题、正文 |
| 次级文字 | `#8A857D` | 注释、页码 |
| 点缀色板（低饱和，每页选 1-2 个，全篇固定一组） | 鼠尾草绿 `#7C9885` / 雾蓝 `#6C8EBF` / 杏黄 `#E8A87C` / 藕粉 `#D9A5B3` | 序号徽章、标签、图形点缀 |
| 卡片描边 | `#EEEBE4` | 卡片边线 |

**规则**：同一页内点缀色不超过 2 个；点缀色用于小面积元素（徽章、圆点、下划线），不用于大色块。

## 字体系统
- font-family：`"PingFang SC","Microsoft YaHei","Noto Sans SC",sans-serif`
- 字号阶梯：页面主标题 40-52px / 卡片标题 24-28px / 正文 16-20px / 注释 13px
- 标题用中等字重（500-600），友好不压迫；重点词可用点缀色加粗

## 版式语言（Bento 在此风格下的形态）
- 卡片：白底 `#FFFFFF` + 1px `#EEEBE4` 描边 + 圆角 rx 20 + 柔投影（`feDropShadow` dy=3 blur=8，黑色透明度 0.06）
- 装饰母题（每页最多 2 个）：柔和渐变气泡（点缀色 6-10% 透明度大圆）；圆形序号徽章（点缀色底 + 白色数字）；要点前的圆点符号
- 图标：2px 圆头线条图标，同页同色；简单几何组合，不用写实风格
- 强调下划线：重点词下加 6px 高的点缀色半透明色条（`opacity 0.3`）

## 页型规范
- **封面**：主标题居中或左置 + 副标题 + 日期署名；背景 1-2 个大渐变气泡
- **目录**：卡片式两栏清单，每项 = 圆形序号徽章 + 章节名
- **章节过渡页**：大序号徽章 + 章节名 + 一句话简介，整页大量留白
- **内容页**：顶部主标题 + 副标题小字，下方 Bento 卡片区（见速查表）
- **步骤页**：横向或纵向步骤流，步骤间用圆头细线连接，序号徽章串联
- **结尾页**：一句话总结 + "谢谢/一起交流"，气泡呼应封面

## 便当网格组合速查
由内容需求驱动选择，卡片数量 1~N 不固定；**最重要的信息放最大的卡片**：
- 单一焦点：一张大卡（约 w1160×h600）——单个知识点或一张核心图示
- 两栏：50/50 对称，或 2/3 主讲解 + 1/3 例子/贴士
- 三栏：三张等宽卡，并列三个要点
- 主次结合：中央大卡 + 两侧竖卡
- 顶部英雄式：顶部宽幅导语卡 + 下方 2-4 张等宽卡
- 混合网格：自由混排，适应知识点的层级展开

## SVG 渲染硬规范
1. `viewBox="0 0 1280 720"`；安全边距 ≥ 60px；卡片间距 ≥ 20px
2. 文字用真实 `<text>`，显式 font-family；中文按字号×1.0、西文按字号×0.55 估宽，禁止溢出卡片
3. 投影必须极轻（透明度 ≤ 0.08），保持轻盈感；禁止纯黑描边
4. XML 转义 `& < >`；分层：背景层/装饰层/内容层
5. 页码右下角 13px 次级灰；徽章尺寸全篇一致

## 自检清单
- [ ] 点缀色每页 ≤ 2 个，只做小面积点缀
- [ ] 每页留白充足，卡片不挤满画布
- [ ] 投影轻、圆角统一（rx 20）、描边统一
- [ ] 序号徽章与图标风格全篇一致
