# 商务咨询风 · 设计系统（Consulting）

参考气质：麦肯锡/BCG 咨询报告。关键词：结论先行、数据说话、干净、严谨、专业。

## 何时使用
工作汇报、经营分析、商业计划书、行业研究、投标提案、述职答辩。主题词里出现"汇报、分析、计划、增长、战略、复盘"时优先匹配。

## 色彩系统
| 角色 | 色值 | 用途 |
|---|---|---|
| 画布底色 | `#FFFFFF` | 每页背景 |
| 主色 | `#0F2B46` 藏蓝 | 标题、页眉条、图表主色 |
| 主文字 | `#1F2937` | 正文 |
| 次级文字 | `#6B7280` | 注释、来源、页码 |
| 强调色（全篇二选一） | `#C8A45C` 金铜 或 `#C0392B` 砖红 | 关键数据、结论下划线 |
| 分隔线 | `#E2E5EA` | 细线、卡片描边 |

**规则**：开题时确定唯一强调色并全篇贯彻；藏蓝承担 90% 的"彩色"，强调色只点睛。

## 字体系统
- font-family：`"PingFang SC","Microsoft YaHei","Noto Sans SC",sans-serif`；数字 `"Arial","Helvetica",sans-serif`
- 字号阶梯：结论式标题 30-34px / 卡片标题 22-26px / 正文 16-18px / 注释 12px
- **标题必须是"一句话结论"**（观点式，如"华东区贡献了 62% 的增量"），禁止用"华东区情况分析"这类名词式标题。

## 版式语言（Bento 在此风格下的形态）
- 卡片：白底 `#FFFFFF` + 1px `#E2E5EA` 描边 + 圆角 rx 8 + 无投影或极轻投影；**卡片顶部加 4px 藏蓝色条**（重点卡用强调色）
- 页眉：左上章节编号 + 章节名（次级灰 13px），下方 1px 细线贯穿；右上放公司/项目名
- 装饰母题（克制）：章节编号大字 01/02/03（藏蓝透明度 0.08，180px）；细线流程箭头
- 图表优先于文字：条形/柱状/折线/瀑布，用 `<rect><line><circle>` 手绘；轴与网格线 1px `#E2E5EA`，数据标签 12-13px 深灰，重点柱/线用强调色，其余用藏蓝或浅蓝 `#7C9CBF`
- 数字排版：关键指标用超大数字（48-64px）+ 小单位 + 一行结论

## 页型规范
- **封面**：白底大留白，主标题藏蓝 44-56px + 副标题 + 日期/机密标注；底部一条 8px 藏蓝色带（可含强调色细条）
- **目录**：左标题右列表，或双栏编号列表，编号藏蓝
- **章节过渡页**：章节编号 + 章节名 + 一句话导语；大量留白
- **内容页**：页眉（章节信息）→ 结论式主标题 → Bento 卡片区（见速查表）→ 底部来源注释
- **数据页**：一页一个核心论点；图表占最大卡片，右侧或下方放"所以呢（So what?）"结论卡
- **结尾页**：总结三要点 + 建议行动（Next Steps）+ 联系方式

## 便当网格组合速查
由内容需求驱动选择，卡片数量 1~N 不固定；**最重要的信息放最大的卡片**：
- 单一焦点：一张大卡（约 w1160×h600）——核心图表或单一论点
- 两栏：50/50 对称，或非对称 2/3 图表 + 1/3 解读
- 三栏：三张等宽卡，并列比较三项
- 主次结合：中央大卡 + 两侧竖卡
- 顶部英雄式：宽幅英雄卡（核心结论/图表）+ 下方 2-4 张等宽卡
- 混合网格：自由混排，适应复杂论证

## SVG 渲染硬规范
1. `viewBox="0 0 1280 720"`；安全边距 ≥ 60px；卡片间距 ≥ 20px
2. 文字用真实 `<text>`，显式 font-family；中文按字号×1.0、西文按字号×0.55 估宽，禁止溢出
3. 每页左下或底部标注数据来源（`来源：xxx`，12px 次级灰）
4. XML 转义 `& < >`；分层：背景层/页眉层/内容层
5. 页码右下角 13px 次级灰；全篇页眉位置像素级一致

## 自检清单
- [ ] 每个标题都是观点/结论，不是名词
- [ ] 每页只有一个核心论点，图表有"所以呢"
- [ ] 强调色全篇统一且只做点睛
- [ ] 有数据来源标注，无编造数字
