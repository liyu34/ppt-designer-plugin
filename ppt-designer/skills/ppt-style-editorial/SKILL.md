# 杂志编辑风 · 设计系统（Editorial）

参考气质：瑞士国际主义平面设计、时尚杂志内页。关键词：大字、留白与密集的节奏对比、不对称、克制的一抹色。

## 何时使用
品牌介绍、创意提案、活动宣传、人物/团队故事、时尚与文化议题。主题词里出现"品牌、理念、发布、故事、设计、艺术"时优先匹配。

## 色彩系统
| 角色 | 色值 | 用途 |
|---|---|---|
| 画布底色 | `#F5F1E8` 米白（纸感）或 `#FFFFFF` | 每页背景，全篇统一 |
| 主色 | `#111111` 近黑 | 标题、正文、大色块 |
| 次级文字 | `#6E6A63` | 注释、图注、页码 |
| 强调色（全篇唯一） | `#FF4D00` 国际橙 或 `#002FA7` 克莱因蓝 | 标题中的词、色块、线条 |

**规则**：全篇只用一个强调色，允许大面积近黑色块；黑白灰承担 95%，强调色出现即焦点。

## 字体系统
- 标题：`"Noto Serif SC","STSong","SimSun",serif`（衬线，杂志感）或重磅黑体 `"Source Han Sans SC","Microsoft YaHei",sans-serif`，全篇二选一
- 正文：`"PingFang SC","Microsoft YaHei","Noto Sans SC",sans-serif`
- 字号阶梯：**封面/章节大标题 80-120px** / 页面主标题 44-60px / 卡片标题 24-28px / 正文 16-18px / 图注 12px
- 允许标题压在色块或图片占位区上；字距可轻微收紧（letter-spacing -1 到 -2）

## 版式语言（Bento 在此风格下的形态）
- 卡片有两种形态（全篇统一规则）：
  1. **开放式**：不用描边底色，仅靠网格位置与细黑线（1px `#111111`）分隔——用于标题区、大段留白区
  2. **色块式**：实色色块卡（近黑或强调色，白字）或白卡 + 1px 近黑描边、直角（rx 0-2）——用于引言、图片占位
- 不对称网格是本风格的灵魂：左右栏宽比常见 2:1、1:2、5:7；标题常压角出血（可贴安全边距边缘）
- 装饰母题：超大衬线数字、`01 — 05` 式页码、竖排小字标签（逐字 `<tspan>` 竖排）、极细分割线、大面积图片占位区（色块 + 角落图注小字）
- 图标：不用圆润可爱图标；用几何符号（■ ● ▲ —）或细线

## 页型规范
- **封面**：大标题 100px+ 可两行，压在米白底或大面积近黑色块上；角落放期号式小字（品牌名/日期）
- **目录**：做成"CONTENTS/目录"大字 + 编号清单，编号用强调色衬线数字
- **章节页**：整页只有一个超大编号 + 章节名，允许强调色整块铺底
- **内容页**：顶部不对称标题区（标题 + 一句导语），下方 Bento 卡片区（见速查表）
- **引言页**：整页一句金句，衬线体，强调色标一个词
- **结尾页**：大字致谢 + 竖排小字署名/联系信息

## 便当网格组合速查
由内容需求驱动选择，卡片数量 1~N 不固定；**最重要的信息放最大的卡片**：
- 单一焦点：一张大卡（约 w1160×h600）——整页金句或大图占位
- 两栏：50/50，或 2/3 + 1/3 非对称（本风格最常用）
- 三栏：三张等宽卡，并列三项
- 主次结合：中央大卡 + 两侧竖卡
- 顶部英雄式：顶部宽幅标题/大图卡 + 下方 2-4 张等宽卡
- 混合网格：自由混排；本风格允许卡片跨越分栏，制造杂志式错落

## SVG 渲染硬规范
1. `viewBox="0 0 1280 720"`；安全边距 ≥ 60px；卡片间距 ≥ 20px（开放式区域例外，但视觉分隔必须清晰）
2. 文字用真实 `<text>`，显式 font-family；大标题按字号×1.0 逐行估宽，两行手动换行，禁止溢出
3. 对比度拉满：米白底配近黑字；色块上只放白色文字
4. XML 转义 `& < >`；分层：背景层/色块层/文字层
5. 页码统一 `01 — 05` 样式，13px 次级灰

## 自检清单
- [ ] 全篇只有一个强调色，出现即焦点
- [ ] 每页有明确的不对称结构与呼吸留白
- [ ] 大标题是页面第一视觉，无元素与其争夺
- [ ] 图片占位区有图注，风格统一
