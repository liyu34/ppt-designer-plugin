# 科技发布会风 · 设计系统（Tech Keynote）

参考气质：Apple 发布会、大型科技公司 Keynote。关键词：深空、聚焦、发光、克制的炫。

## 何时使用
产品发布、技术分享、AI/硬件/互联网主题、年度旗舰汇报。主题词里出现"发布、未来、智能、芯片、平台、生态"时优先匹配。

## 色彩系统
| 角色 | 色值 | 用途 |
|---|---|---|
| 画布底色 | `#0A0A0F`（可加对角渐变至 `#14141F`） | 每页背景 |
| 主文字 | `#F5F7FA` | 标题、正文 |
| 次级文字 | `#A1A7B3` | 注释、来源、页码 |
| 强调色 A | `#3B82F6` 电光蓝 | 关键词、数据高亮 |
| 强调色 B | `#22D3EE` 科技青 | 渐变搭档、图形点缀 |
| 强调色 C | `#8B5CF6` 紫 | 仅封面/章节页可用 |

**规则**：每页最多出现 2 种强调色；高亮必须落在全页最重要的词或数字上，其余文字保持白灰。

## 字体系统
- font-family：`"PingFang SC","Microsoft YaHei","Noto Sans SC",sans-serif`（数字可用 `"DIN Alternate","Arial",sans-serif`）
- 字号阶梯：发布会金句 64-88px / 页面主标题 44-56px / 卡片标题 26-30px / 正文 16-20px / 注释 13px
- 标题加粗（font-weight 700-800），金句页只放一句话。

## 版式语言（Bento 在此风格下的形态）
- 卡片：填充 `rgba(255,255,255,0.04)` + 描边 1px `rgba(255,255,255,0.10)` + 圆角 rx 16 + 轻投影（黑色 `feDropShadow`，透明度 0.5）
- 强调卡片：描边换 1.5px 强调色渐变（`<linearGradient>` 蓝→青），内部可加 `rgba(59,130,246,0.08)` 微光填充
- 装饰母题（全篇统一，每页最多 2 个）：右下/左上超大发光圆（径向渐变，透明度 ≤ 0.15）；细网格线（1px `rgba(255,255,255,0.05)`）；超大半透明数字（300px，透明度 0.06）
- 图标：1.5-2px 圆头描边线条图标，白色或强调色

## 页型规范
- **封面**：金句主标题居中或左对齐压角 + 副标题 + 发布方/日期小字；背景放最大的发光圆
- **目录**：章节编号用渐变大数字 01/02/03，右侧或下方接章节名
- **章节页**：整页只放章节编号 + 章节名，装饰母题放大
- **内容页**：顶部主标题一行，下方 Bento 卡片区（见速查表）
- **数据页**：最大卡片放核心指标（超大数字 + 单位），旁边卡片放对比图（条形/折线，用 `<line><rect><circle>` 手绘，坐标轴用次级灰）
- **结尾页**：一句话致谢/愿景 + 联系方式小字

## 便当网格组合速查
由内容需求驱动选择，卡片数量 1~N 不固定；**最重要的信息放最大的卡片**：
- 单一焦点：一张大卡（约 w1160×h600）——单一有力信息或详细图表
- 两栏：50/50 对称，或非对称 2/3 主内容 + 1/3 辅助
- 三栏：三张等宽卡，并列比较
- 主次结合：一张居中大卡 + 两侧竖卡
- 顶部英雄式：顶部宽幅英雄卡 + 下方 2-4 张等宽卡
- 混合网格：自由混排多种尺寸，适应复杂内容

## SVG 渲染硬规范
1. `viewBox="0 0 1280 720"`；安全边距 ≥ 60px；卡片间距 ≥ 20px
2. 文字用真实 `<text>`，显式 font-family；中文按字号×1.0、西文按字号×0.55 估宽，禁止溢出卡片
3. 深色底上正文对比度必须够（主文字 #F5F7FA）；禁止大面积纯白色块
4. XML 转义 `& < >`；分层：背景层/装饰层/内容层
5. 页码右下角，次级灰 13px，格式 `03 / 12`

## 自检清单
- [ ] 强调色 ≤ 2 种/页，高亮只给最重要的词
- [ ] 装饰母题 ≤ 2 个/页，透明度不压过正文
- [ ] 金句页无第二焦点
- [ ] 图表轴与标签用次级灰，数据点用强调色
