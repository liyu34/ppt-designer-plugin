# 新中式风 · 设计系统（New Chinese）

参考气质：故宫文创、观夏、茶事品牌。关键词：宣纸、墨、朱砂、留白、东方意境、现代极简的骨。

## 何时使用
传统文化、非遗、文旅推介、茶/酒/餐饮品牌、博物馆展览、节日庆典、国学分享。主题词里出现"文化、传承、东方、山水、茶、非遗、节气"时优先匹配。

## 色彩系统
| 角色 | 色值 | 用途 |
|---|---|---|
| 画布底色 | `#F7F3EA` 宣纸色 | 每页背景 |
| 主文字（墨） | `#2B2B2B` | 标题、正文 |
| 次级文字（淡墨） | `#8C8578` | 注释、页码、题跋小字 |
| 强调色（朱） | `#C3272B` 朱砂红 | 印章、重点词、点缀线 |
| 辅助色（金/赭） | `#B8860B` 金 或 `#9E6B3F` 赭石 | 细线、图形描边（全篇选其一） |
| 卡片描边 | `#C9BFA8` | 边框线 |

**规则**：朱砂红只做点睛（印章、一个词、一条线），占比 ≤ 5%；整体画面以墨 + 宣纸为主。

## 字体系统
- 标题：`"Noto Serif SC","STSong","SimSun",serif`（宋体/衬线，书卷气）
- 正文：`"PingFang SC","Microsoft YaHei","Noto Sans SC",sans-serif`（黑体保证可读）
- 字号阶梯：页面主标题 44-60px / 卡片标题 24-28px / 正文 16-18px / 题跋注 12-13px
- 标题允许竖排（逐字 `<tspan>`，每字一行，行距 = 字号 × 1.15）；竖排仅用于标题或短句，正文一律横排

## 版式语言（Bento 在此风格下的形态）
- 卡片：半透明白 `rgba(255,255,255,0.6)` + 1px `#C9BFA8` 描边 + 直角或微圆角（rx 0-4）+ 无投影（纸片叠放感可用错位 2px 的第二层边框模拟）
- 装饰母题（全篇统一，每页最多 2 个）：
  - **印章**：20-32px 正方形朱砂红块 + 白色 1-2 字（篆意可用普通字体代替），盖在标题旁或角落
  - **山水剪影**：底部 `<path>` 贝塞尔曲线淡墨山形（透明度 0.08-0.15），或远山两叠
  - **回纹/细线边框**：距安全边距 10px 的 1px `#9E6B3F` 细框（仅封面、章节、结尾页用）
  - **云纹**：简单弧线组合，淡墨
- 分区允许用圆形窗棂（大圆轮廓内放卡片）与扇形替代部分矩形卡，全篇统一选用
- 图标：细线水墨风，1.5px `#2B2B2B` 或赭石描边

## 页型规范
- **封面**：竖排大标题（或超大横排宋体）+ 印章 + 一句引文题跋；底部淡墨远山
- **目录**：「目 录」两字居中或竖排 + 编号章节名（编号用"壹 贰 叁"或"01"全篇统一）
- **章节页**：细线边框 + 竖排章节名 + 印章；大量留白
- **内容页**：横排主标题 + 侧边竖排小字标签，下方 Bento 卡片区（见速查表）
- **引文页**：整页一句古文/金句，宋体居中，右下题跋小字 + 印章
- **结尾页**：致谢语（如"谢谢观赏 / 敬请指正"）+ 山水呼应封面

## 便当网格组合速查
由内容需求驱动选择，卡片数量 1~N 不固定；**最重要的信息放最大的卡片**：
- 单一焦点：一张大卡（约 w1160×h600）——整页引文或核心图示
- 两栏：50/50 对称，或 2/3 主文 + 1/3 配图占位（图占位用淡墨色块 + 角注）
- 三栏：三张等宽卡，并列三项（适合"三个典故/三款产品/三处景点"）
- 主次结合：中央大卡 + 两侧竖卡（适合主图 + 两侧竖排注释）
- 顶部英雄式：顶部宽幅横卷式大卡（如长卷山水/时间轴）+ 下方 2-4 张等宽卡
- 混合网格：自由混排，允许圆窗卡与矩形卡混搭

## SVG 渲染硬规范
1. `viewBox="0 0 1280 720"`；安全边距 ≥ 60px；卡片间距 ≥ 20px
2. 文字用真实 `<text>`，显式 font-family；竖排逐字 `<tspan>`；中文按字号×1.0 估宽，禁止溢出
3. 不引入外部图片；纹理、山水、云纹全部用 `<path>`/`<pattern>` 手绘
4. XML 转义 `& < >`；分层：背景层/装饰层（山水/边框）/内容层
5. 页码右下角淡墨 13px；印章位置全篇一致（如固定右上或标题右侧）

## 自检清单
- [ ] 朱砂红 ≤ 5%，只做点睛
- [ ] 山水/云纹/印章全篇统一画法与透明度
- [ ] 竖排仅用于标题短句，正文横排可读
- [ ] 留白充分，画面"疏可走马"，无元素挤塞
